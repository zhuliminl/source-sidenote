# 同类项目与差异化（2026-10-28）

不存在“完全没有竞品”的结论。下列为官方说明调研，未做安装性能/质量横评。

- [How It Works](https://marketplace.visualstudio.com/items?itemName=Juandgarin.how-it-works)：VS Code 文件解释侧面板、Markdown 缓存、模型配置。与核心阅读交互接近。
- [DeepWiki-Open](https://github.com/AsyncFuncAI/deepwiki-open)：AI 仓库 Wiki 生成，与项目级说明重叠。
- [RepoDoc](https://arxiv.org/abs/2604.26523)：仓库知识图谱辅助文档生成与增量更新。[实现](https://github.com/SYSUSELab/RepoDoc)。

定位：轻量本机服务、多项目与多编辑器共享逐文件说明，并提供覆盖/过期/复查记录。竞争优势需由实际使用证明，不能将覆盖率包装成准确率。

本项目目前独立实现，没有复制上述项目代码。
